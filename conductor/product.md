# Product Definition — Volume Cartographer

## Project Name

Volume Cartographer

## Description

A toolkit for processing volumetric CT data to extract and flatten surfaces of ancient documents.

## Problem Statement

Ancient scrolls and manuscripts are too fragile to physically unroll, requiring virtual unwrapping from CT scans to read their contents without destructive handling.

## Target Users

- **Researchers and scientists** working on ancient document recovery (e.g., Vesuvius Challenge participants)
- **Digital humanities teams and archaeologists** with CT scan data of fragile manuscripts
- **Developers** building virtual unwrapping pipelines on top of the VC library

## Key Goals

1. Provide both GUI and CLI tools for the full segmentation-to-texture pipeline
2. Produce high-quality, readable texture images from CT volumes of ancient scrolls
3. Maintain a modular, extensible C++ library for algorithm research and development
