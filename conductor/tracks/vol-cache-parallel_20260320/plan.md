## Phase 2: Fix Cache Miss Lock Structure

Eliminate disk I/O under the global write lock. The exclusive write lock should only protect LRU bookkeeping, not the TIFF read itself.

### Tasks

- [ ] Task 2.1: Refactor `cache_slice_()` in `Volume.cpp`: acquire per-slice mutex → load TIFF (no global lock held during IO) → acquire `cacheMutex_` write-lock briefly to insert into LRU → release
- [ ] Task 2.2: Verify the double-checked locking pattern is correct after the refactor (check-under-shared-lock → acquire-per-slice-mutex → re-check → load → insert)
- [ ] Task 2.3: Audit `LRUCache::get()` — ensure it only takes a write lock when it actually mutates the access-order list (cache hit promoting an item); if the item is already at the front, avoid the write lock
- [ ] Task 2.4: Run stress test under TSan; fix any races
